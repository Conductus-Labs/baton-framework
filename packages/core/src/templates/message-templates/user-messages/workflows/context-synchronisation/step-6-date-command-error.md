# Date Command Error

❌ Error: Cannot get current date/time from system

**Command:** `date -u +"%Y-%m-%dT%H:%M:%SZ"` (ISO 8601 format)

**Possible Causes:**
- System date command not available
- Command format not supported on this platform
- System time not accessible

**Recovery:**
- Verify system date command is available
- Check platform compatibility (Unix/Git Bash vs Windows)
- Ensure system time is accessible
