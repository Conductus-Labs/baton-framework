# Missing Required Parameter Error

❌ Error: Missing required parameter

**Parameter:** `agent_short_name`

The `agent_short_name` parameter is required to synchronize context. This parameter must be provided either:
- As a command argument, OR
- Extracted from the current agent context

**Recovery:**
- Provide the `agent_short_name` parameter when calling the command
- Ensure you are running this command from within an agent session where the agent context is available
