# Error: Agent Boundaries Not Found

❌ Error: Agent boundaries file not found

**File:** `.baton/boundaries/{agent_name}-boundaries.md`
**Operation:** {operation}

**Issue:** The agent boundaries file does not exist. For update or delete operations, the file must exist.

**Solution:**
1. Use the `add` operation to create the agent boundaries file and add the first rule
2. Or manually create the agent boundaries file from the template

Please use the add operation first, then try update or delete operations.
